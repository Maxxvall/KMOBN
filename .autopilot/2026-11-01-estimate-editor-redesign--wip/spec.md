# Спецификация: Редизайн верхней области редактора смет + фильтр периода в истории

## Задача
Пользователь недоволен верхней частью редактора смет: «мне не нравится внутри смет вот эти моменты в самом верху» — пять рядов текста и кнопок до содержимого, слова там, где достаточно иконки, криптичные сокращения (СС/ЕВ, Р/М/Д) без подсказок, три красных элемента спорят между собой. Нужен современный, компактный и удобный вид — одинаково на сайте и в приложении на ПК. Заодно: начать разбивать файл на 2401 строку на компоненты и добавить фильтр смет по периоду в историю.

## Решение
Верхняя область редактора сжимается: заголовок с бейджем статуса, поля в один компактный ряд, «Пояснение» сворачивается в строку-пилюлю, ряд шаблона и нижняя панель становятся панелью инструментов с иконками. У главных действий — иконка с подписью, у второстепенных — только иконка с подсказкой при наведении. Красный остаётся только у «Сохранить» и ИТОГО. В истории смет появляется фильтр по периоду дат. Всё это — в новых файлах-компонентах: первый шаг выноса верхней области из монолита.

## Решения по реализации
- **Иконки**: `@devigner-ui/icons` точной версией; только именованные импорты (tree-shaking — бандл не раздувается); имена экспортов сверять с README пакета при сборке. Почему: выбор пользователя, 0 зависимостей, MIT/CC-BY-4.0.
- **devignerui-компоненты**: `npx devignerui add badge delete-button date-range-picker`; после установки привести к токенам тёмной темы проекта (border/surface/primary). Для фильтра периода допустим фолбэк на пару `<input type="date">` в рецепте истории, если пикер плохо ложится в тёмную тему — решение фиксируется в тикете.
- **Красный demotion**: «По шаблону» — outline-стиль с иконкой; красный остаётся у «Сохранить» и ИТОГО. Почему: три красных элемента спорят, primary-акцент один на вид.
- **Тултипы**: native `title` + `aria-label` (конвенция проекта, работает в Electron), библиотеку не вводим.
- **Элементы без группы R13**: «AI» (средняя кнопка ряда шаблона) — иконка-only с `title="AI-генерация"`; «+ Раздел...» остаётся select-ом (это выпадающий список, не кнопка) с `aria-label="Добавить раздел"`; индикатор «v{version} · дата» сохраняется в первой группе панели как компактный span, как сейчас.
- **СС/ЕВ**: title «Сухостроганая доска» / «Естественной влажности» — формулировки из `BoardMaterialSwitchModal.tsx`.
- **Refactor**: состояние остаётся в `EstimateEditor` (поднято), извлечённые компоненты — презентационные с типизированными пропсами; обработчики не меняются. Границы — `interfaces.md`.
- **Процесс (R06)**: код пишется под скиллами ub-mode (make it work → make it right), impeccable, ui-ux-pro-max, emil-design-eng; правила — `interfaces.md`.
