## Что должно заработать

Пользователь удерживает заголовок 400 мс и переносит целый раздел мышью/пальцем на любое место, видя источник и позицию вставки. Короткий клик сворачивает как прежде. После сохранения выбранный порядок сохраняется и используется во всех документах сметы. Новые разделы в конце, старые сметы при открытии не переставляются. Редактор и его окна используют согласованные SVG-иконки вместо смайликов и разнородных glyph.

## Критерии приёмки

- [ ] Полный порядок задаётся сервисом через существующий sectionSnapshot; неверный набор ids отвергается; labels custom/legacy сохраняются; items, notes, actuals и total не меняются; reorder/no-op покрыты регрессиями.
- [ ] Открытие прежней сметы не переставляет её и не делает dirty; add/remove/readd оставляют действующий порядок, новые ids в конце, прежние места удалённых ids не восстанавливаются. AI/комплекты/вставка сохраняют ручной порядок.
- [ ] Перестановка регистрируется dirty, проходит Save/Unsaved flow и lifecycle, повторное открытие и JSON transfer сохраняют порядок. Точные дубли и счётчик импорта учитывают order-only различия.
- [ ] Plain/colored/contract PDF следуют новому порядку с проверкой реального экспортного входа autoTable/model, а не только вызова helper; сохраняют прежнюю политику пустых разделов и суммы.
- [ ] Excel PlanFact одной сметы группируется по этому порядку, не мутируя текущие rows и сортировку экранной аналитики. Сравнения двух смет/калькулятор не затронуты.
- [ ] Header после 400 мс активирует перенос с preview, выделением и линией вставки; отпускание применяет одну перестановку; достижимы первое/последнее и удалённое место через edge-scroll; нумерация следует порядку.
- [ ] Короткий клик сворачивает; drag/long hold не сворачивает на отпускании. Самостоятельные кнопки header не запускают перенос; button-в-button устранён. При нуле/одном разделе нет фиктивного drag.
- [ ] Touch ранний свайп прокручивает и отменяет ожидание; после удержания перенос не превращается в page scroll. Не полагаться на позднюю смену touch-action. Для проверяемого seam добавить фокусный тест таймера/отмены/commit/подавления клика; физический touch без устройства не объявлять проверенным.
- [ ] Escape/pointercancel/blur/смена сметы/unmount отменяют жест без изменения Estimate и чистят timers/listeners/capture/RAF; второй pointer/right button не перехватывают жест; архивные ограничения соблюдены; имеется доступный клавиатурный способ.
- [ ] Видимые emoji/glyph действий/пресетов/section.icon в редакторе и его реальных окнах заменены SVG уже установленной библиотеки. Арифметические символы и данные пользователя остаются текстом; domain registry вне редактора не мигрируется.
- [ ] Close/Copy/Clipboard/Chevron/Pen/Note/Add/Trash согласованы по виду/размеру; обычные действия нейтральные, удаление красное; title/aria-label и декоративные aria-hidden. Существующие важные подписи и действия сохранены.
- [ ] npm run test и npm run typecheck пройдены; новые/затронутые поведенческие тесты содержат реальные регрессии. Приложение, dev/Electron/E2E/lint/build и пользовательские данные не использовались для проверки.
