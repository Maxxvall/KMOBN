## Что должно заработать

Пользователь открывает любую существующую смету и назначает до двух меток в строке метаданных. Добавляет свои метки, переименовывает их во всех сметах единым действием и удаляет без удаления смет. В текущей истории выбирает несколько меток: видны только сметы со всеми выбранными одновременно. Справочник и назначения сохраняются офлайн, в облако и JSON backup. Расчёт дома использует только вручную отмеченные типовые проекты независимо от статуса и не подменяет их обычными сметами.

## Критерии приёмки

- [ ] Системная «Типовые проекты» доступна по умолчанию; старым сметам ничего не назначено. Нельзя её удалить, переименовать или подменить при импорте.
- [ ] Пользовательские метки создаются с валидным уникальным именем и стабильным ID, глобально переименовываются; удаление снимает метку с отображения/слотов всех смет и не возрождается stale save/import.
- [ ] В метаданных редактора доступны ноль/одна/две метки; третья не назначается. labels-only change считается dirty, проходит save/reopen и неизменное сохранение не плодит очередь.
- [ ] Новая версия сохраняет метки; отдельная копия/share import и калькуляторный черновик пусты. Старые форматы без меток открываются и импортируются.
- [ ] Несколько выбранных меток в фильтре текущих дают AND; контрольный пример typical+баня исключает typical-only. Архив остаётся независимым, остальные фильтры/сортировка/последние версии работают как прежде; есть reset/empty и без метки.
- [ ] Дефиниции и tombstones переживают normalise/base/merge/conflict/queued persistence; разные offline edits сливаются, конкурирующие одинаковые ID не теряются молча. Данные разделов и порядок не меняются.
- [ ] JSON backup и export-only-estimates сохраняют разрешимые назначения; restore не возрождает удалённые определения и не перетирает актуальное локальное имя старым snapshot.
- [ ] Все source selectors, scope additions, primary/retry/AI fallback/AI review используют только пригодные nonarchived typical; статус и давность не мешают. Unlabelled approved/reference-name не обходят фильтр. При версиях не брать stale вместо latest.
- [ ] Без типовых — ясное сообщение и никакой подмены обычными estimates/передачи их в AI. Тексты UI соответствуют новым источникам.
- [ ] Адресные значимые тесты RED → GREEN и финальный `npm run check` пройдены с реальным exit code; существующее полезное покрытие сохраняется. Итог evidence сохранён в кратком отчёте.
