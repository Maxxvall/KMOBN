# Состояние предыдущего прогона

Источник: `.autopilot/PROGRESS.md`, прочитан полностью 2026-11-05; последняя приёмка — 2e1ea06.

## Договорились

- Главные правила проверки — пользовательский AGENTS.md: сервисы и расчёты требуют npm run test; Electron E2E только для desktop integration, build только для packaging/config/release.
- Порядок разделов индивидуален для сметы, сохраняется в её документах; новые разделы добавляются в конец. Короткий клик сворачивает; удержание около 400 мс начинает перенос мышью или пальцем.
- Общая кнопка сворачивания меняет только просмотр.
- Иконки действий нейтральные, удаление красное; «Сохранить» и ИТОГО сохраняют красный акцент.
- Фильтр периода истории не меняет сортировку и экспорт.
- Платежи не возвращаем; остатки прошлого прогона ранее оставляли отдельными.

## Не доделано

- Ручная проверка мышью, пальцем, длинной сметы и раскладки.
- Дальний рефакторинг EstimateEditor, AI-окон и панели «Факт».
- DateRangePicker использует нативные date-инпуты; полный devignerui-компонент не установлен.

## Известные баги

- Краткий индикатор успеха при отмене удаления шаблона.
- Раскрытое «Пояснение» без aria-связи с подписью.
- Стили полей дублируются в EstimateEditor.tsx и estimate-editor/shared.ts.

## Изменено после сборки

- 271a1b9 — общее сворачивание разделов и плавный перенос сметы. Изменение уже учтено в PROGRESS.md: preview через RAF, порядок применяется при отпускании; 381 тест и typecheck пройдены. В этой фазе повторные продуктовые проверки не требуются.
