## Что должно заработать

Ctrl/Cmd+K или кнопка в шапке открывают палитру команд: поиск и открытие сметы по
клиенту/номеру, «Новая смета», переход в любой из 9 разделов, «Экспорт PDF» и
«AI-генерация» для активной сметы. Ничего не найдено — понятный пустой экран. Палитра
грузится лениво, отдельным чанком. Иконки навигации шапки — из пакета.

## Критерии приёмки

- [ ] Ctrl/Cmd+K открывает палитру из любого места приложения; Esc и клик-мимо закрывают; фокус-ловушка внутри, фокус возвращается на источник
- [ ] Кнопка в Header (иконка поиска, aria-label «Поиск и команды») открывает палитру; state открытости — в `UiState` (initialUiState), не отдельный useState
- [ ] Поиск по клиенту/номеру находит смету, выбор открывает её (`handleEditPendingEstimate`); «Новая смета» (`handleCreateNew`); переходы в 9 разделов через `handleNavigationAttempt` — при dirty-редакторе открывается модалка несохранённого
- [ ] «Экспорт PDF» и «AI-генерация» — команды из существующих потоков, видимы только когда применимы (есть активная смета)
- [ ] Вложенные страницы палитры работают (рецепт); пустой результат — экран «Ничего не найдено» с подсказкой
- [ ] Компонент подгружается через React.lazy (отдельный чанк); 10 inline-SVG NavIconName в Header заменены на иконки пакета
- [ ] `npm run check` зелёный
