## Режим

**Autopilot: полуавтомат (semi), глубина обычная.** Спрашиваю только реальные развилки на брифинге, дальше собираю сам. Фазы: Требования → Брифинг → Спецификация → План → Разработка (субагенты) → Код-ревью → Приёмка. Дашборд `.autopilot/dashboard.html`.

## Бриф (требования из слов пользователя)

1. Установить `@devigner-ui/icons` (пин версии), использовать иконки в шапке/панелях редактора смет.
2. Современный, компактный, удобный стиль верхней области сметы — как на сайте (web), так и в приложении на ПК (один React-компонент, правка одна на оба).
3. Заменить слова подходящими иконками там, где уместно (Сравнить, В шаблон, Комплекты, Разделы, Факт, ИТОГО Р/М/Д и т.д.).
4. `npx devignerui add badge` — бейджи там, где нужны (статус сметы «Черновик» и т.п.).
5. `npx devignerui add date-range-picker` и «прикольная кнопка удаления» из devignerui — использовать в смете, где подходят (кнопка удаления — у удаления выбранного шаблона вместо голого ✖; date-range-picker — оценить на брифинге, куда он реально встаёт, без высосанных мест).
6. Начать рефакторинг: разбивать `EstimateEditor.tsx` на компоненты по файлам, начинай с верхней области (шапка, поля, пояснение, ряд шаблона, тулбар).

- **Phase 3 (Спецификация)**: notes.md по коду (уже разведан), spec.md, interfaces.md — проектные правила из AGENTS.md (без автозапуска dev/build/test, не трогать Supabase-креды).
