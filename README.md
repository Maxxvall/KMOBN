# Каркас Мастер - Генератор смет

Десктопное и веб-приложение для автоматического создания строительных смет.

## Установка

### Веб-версия
1. Перейдите на сайт приложения
2. Авторизуйтесь через email или Google
3. Начните работать

### Десктопная версия (.exe)
1. Скачайте установщик с [GitHub Releases](https://github.com/your-repo/releases)
2. Запустите файл установщика
3. Следуйте инструкциям установщика
4. Запустите приложение из меню "Пуск" или рабочего стола

## Разработка

### Установка зависимостей
```bash
npm install
```

### Запуск веб-версии
```bash
npm run dev
```

### Запуск десктоп-версии
```bash
npm run dev:electron
```

### Сборка .exe


## Архитектура

### Стек технологий
- **Frontend**: React 19.2 + TypeScript 5.8
- **Сборка**: Vite 6.2
- **Стили**: Tailwind CSS 3.4
- **Бэкенд**: Supabase (PostgreSQL)
- **Локальное хранилище**: IndexedDB
- **Десктоп**: Electron 33.x

### Структура проекта
```
СметыKMOBN/
├── src/                          # Основной код
│   ├── components/               # React компоненты
```

## Функциональность

### Вкладки приложения

#### Десктопная версия (4 вкладки)
1. **Сметы** - список и редактирование смет
2. **Цены** - каталог цен на материалы
3. **Работы и комплекты** - каталог работ и комплектов
4. **Аналитика** - графики и статистика

#### Веб-версия (обновленная)
- Убрана вкладка "Информация" (Wiki)
- Добавлено модальное окно профиля

### Модальное окно профиля
- **Личные данные**: имя, email, аватар, дата регистрации
- **Статистика**: количество смет, последняя активность, общий объем работ, топ-5常用 материалов, время в приложении
- **Настройки**: тема, язык, уведомления, экспорт данных, очистка кэша

### Система авторизации
- **Онлайн**: email/пароль или вход через Gmail
- **Офлайн**: сохраненный ключ доступа
- **Синхронизация**: автоматическая при подключении к интернету

### Синхронизация данных
- **Что синхронизируется**: сметы, шаблоны, цены материалов, работы, комплекты, расчеты зарплат
- **Что НЕ синхронизируется**: калькулятор (нет в десктопе), Wiki (нет в десктопе)

## Конфигурация

### Переменные окружения
Создайте файл `.env`:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Настройка Electron
Файл `electron/main.ts` содержит основную конфигурацию:
- Размеры окна
- Настройки безопасности
- Обработчики IPC
